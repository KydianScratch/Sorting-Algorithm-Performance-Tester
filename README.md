Algorithm Describtions:

- Bubble Sort: a basic, but less efficient sorting method. Despite having similar time and space complexities to other algorithms, it has shown high resource consumption compared to the other algorithms in this test. Better used with smsller samples.

- Selection Sort: the common sorting strategies humans tend to use in their daily activities. Has basic resource consumption, and showed good results in the test. Can be used when the need for speed and memory effeciently is equaly important.

- Insertion Sort: yet again, and algorithm with the same complexity values as the previous ones, yet it performed a tiny bit less effeciently in this test. Should also be used when speed and memory effeciently are similarly required.

- Merge Sort: the leading sorting algorithm in terms of time complexity, but performs worse at preserving memory. The best option when time matters and enough memory is provided.

- Quick Sort: performs better than the merge sort in terms of space complexity, but has the standard higher time complexity. Better used with lower memory capacities.

Algorithm Complexity:

- Bubble Sort: time O(n^2) - space O(1).
- Selection Sort: time O(n^2) - space O(1).
- Insertion Sort: time O(n^2) - space O(1).
- Merge Sort: time O(n log n) - space O(n).
- Quick Sort: time O(n^2) - space O(log n).
